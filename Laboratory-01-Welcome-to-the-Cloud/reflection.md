## Reflection

This activity helped me understand the basics of using a cloud-based Linux environment through KillerCoda. I learned how to access the Ubuntu playground, open the terminal, and use simple Linux commands to check information about the system.

I also learned how to create a new user account and give it the needed permissions. Creating the **pdbagayan** account and logging into it helped me understand how users, home directories, and `sudo` privileges work in Linux.

One thing I learned from this activity is that Linux commands need to be entered correctly because each command has a specific purpose. Using commands like `whoami`, `pwd`, and `hostname` helped me check my username, current location, and system hostname. Overall, this activity made me more comfortable using the Linux terminal and gave me a better understanding of how Linux is used in cloud computing.
