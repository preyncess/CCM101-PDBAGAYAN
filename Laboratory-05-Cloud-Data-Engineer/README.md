# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focuses on using MinIO as an object storage solution. The main purpose is to create a basic storage system for a photo-sharing application where many user-uploaded images can be stored safely and accessed when needed.

## Objectives

* Identify the different types of cloud storage.
* Explain the differences between Block Storage, File Storage, and Object Storage.
* Deploy MinIO using Docker.
* Open and manage the MinIO Web Console.
* Create a bucket named `client-photos`.
* Upload a sample file into the bucket.
* Document the different steps completed during the deployment.

## Tools Used

* KillerCoda Ubuntu Playground
* Docker
* MinIO
* MinIO Web Console
* Linux Terminal
* Git and GitHub
* Markdown

## Skills Learned

* Understanding the purpose and uses of different cloud storage types
* Deploying a cloud storage service through Docker
* Checking and managing Docker containers
* Using the MinIO Web Console
* Creating and managing storage buckets
* Uploading files as objects in cloud storage
* Practicing Linux command-line operations
* Writing documentation for cloud infrastructure activities
