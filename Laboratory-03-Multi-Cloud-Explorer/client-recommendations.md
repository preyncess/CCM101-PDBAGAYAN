# Client Recommendations

## Client A – Startup Company

### Recommended Platform: AWS

I recommend AWS because it provides flexible and scalable services that can support a startup with a limited budget. The company can start with smaller resources and increase them as the mobile application gains more users. AWS also provides many services that can be used to build and deploy applications. This makes it suitable for a startup expecting rapid growth.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- Amazon VPC

---

## Client B – University

### Recommended Platform: Microsoft Azure

I recommend Microsoft Azure because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure provides strong integration with Microsoft technologies, making migration easier for the university's existing environment. It can also support hybrid cloud setups, allowing some systems to remain on-premises while other services move to the cloud. This can help the university migrate gradually.

### Possible Services

- Azure Virtual Machines
- Azure Blob Storage
- Microsoft Entra ID
- Azure Virtual Network

---

## Client C – AI Research Company

### Recommended Platform: Google Cloud Platform

I recommend Google Cloud because the company focuses on Artificial Intelligence and Machine Learning applications. Google Cloud provides AI and ML services and powerful computing resources that can support demanding workloads. It also provides tools for data processing and scalable application development. These features make it suitable for an AI research company.

### Possible Services

- Compute Engine
- Vertex AI
- Cloud Storage
- Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Platform: AWS

I recommend AWS because it provides scalable infrastructure and a global cloud network suitable for an international e-commerce platform. The company can deploy applications in multiple regions and use automatic scaling to handle changes in customer traffic. AWS also provides services for databases, storage, networking, and monitoring. These capabilities can help maintain availability while the business grows.

### Possible Services

- Amazon EC2
- Amazon S3
- Amazon RDS
- Amazon VPC
- Elastic Load Balancing
- Auto Scaling

---

# Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Flexible services and scalable infrastructure |
| Enterprise Organization | AWS | Wide range of enterprise cloud services |
| Microsoft Environment | Azure | Strong Microsoft integration |
| AI / Machine Learning | GCP | Strong AI and ML capabilities |
| Kubernetes Deployment | GCP | Google Kubernetes Engine provides strong Kubernetes support |
| Global Web Application | AWS | Large global infrastructure and scalability |
