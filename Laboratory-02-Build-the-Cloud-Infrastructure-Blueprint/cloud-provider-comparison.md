# Checkpoint 4 – Major Cloud Service Providers

## Cloud Provider Overview

| Component | Amazon Web Services (AWS) | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Blob Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network (VNet) | Google Cloud VPC |
| IAM | AWS IAM | Microsoft Entra ID | Google Cloud IAM |

---

## 1. Which Provider Has the Widest Selection of Services?

Among the three major cloud providers, **AWS** is known for having a very extensive collection of cloud services. It offers solutions for computing, storage, databases, networking, security, artificial intelligence, data analytics, and many other technologies. This wide selection gives businesses more choices when creating and managing cloud-based systems.

---

## 2. Which Cloud Platform Is Best for an Organization Using Microsoft Products?

For an organization that mainly relies on Microsoft products, I would choose **Microsoft Azure**. Azure has strong compatibility with Microsoft's existing technologies, including Windows Server, Microsoft 365, and Microsoft Entra ID. This integration can make it easier to move existing systems and services to the cloud.

---

## 3. Which Provider Is Known for AI, ML, and Kubernetes?

**Google Cloud Platform (GCP)** is well known for its capabilities in **Artificial Intelligence, Machine Learning, and Kubernetes**. Google is the original creator of Kubernetes and offers **Google Kubernetes Engine (GKE)** for managing containerized applications. It also provides several tools and services for building and deploying AI and ML applications.

---

## 4. What Similarities Exist Among AWS, Azure, and Google Cloud?

The three cloud providers have many common features. All of them provide essential cloud infrastructure such as **virtual computing, storage, networking, and identity management**.

They also allow organizations to access computing resources without purchasing and maintaining their own physical servers. Another similarity is **scalability**, which allows cloud resources to be increased or reduced based on the organization's requirements.
