# Automation Research

## 1. Bash Script

A Bash script is a file that contains several Linux commands that can be executed automatically. The `#!/bin/bash` line is called the shebang, and it tells the computer that the script should be run using Bash.

## 2. Variables

Variables are used to store information that a script needs, such as folder locations or file names. For example, `$BACKUP_DIR` can store the location of the backup folder, so the path only needs to be changed in one place if an update is needed.

## 3. Cron Job

A cron job is a Linux feature that allows tasks to run automatically at a scheduled time or date. It is useful for cloud administration because it can handle repeated tasks like backups without needing to manually run the commands each time.
