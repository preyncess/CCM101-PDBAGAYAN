# Mission Reflection

Completing the Cloud Automation Engineer mission helped me understand the importance of automation in cloud computing. When an organization handles many servers, doing the same tasks manually can take a lot of time and may lead to mistakes. Automation helps administrators perform repeated tasks more consistently, such as making backups, checking systems, and managing services. It also makes it easier to handle larger cloud environments.

However, I also learned that automation can cause problems if scripts are not tested carefully. For example, a wrong command running on hundreds or thousands of servers could delete important files or change data that should not be changed. Because of this, scripts should be checked and tested in a safe environment before being used. It is also important to give scripts only the permissions they actually need and to have proper backup and recovery plans.

Creating a Bash script was different from using a Docker Compose YAML file in Mission 6. Bash scripts use commands, variables, and instructions to perform tasks one by one. On the other hand, Docker Compose YAML is mainly used to define and configure services for running containers. Although they are different, both tools help make cloud tasks easier and more automated.

Looking back at my GitHub portfolio from Laboratory 1 to Laboratory 9, I can see how my knowledge of cloud computing has improved. I started with basic cloud concepts and infrastructure, then learned about containers, data services, deployment, monitoring, security, and automation. These activities showed me that cloud computing is not only about running applications but also about keeping systems reliable, secure, and properly managed.

The role I enjoyed the most was the Cloud Automation Engineer because using scripts can reduce repetitive work and make tasks easier to perform. I also liked the Security Engineer role because protecting systems and data is very important. Overall, these missions helped me develop practical cloud skills and taught me the importance of testing, documentation, security, and continuous learning.
