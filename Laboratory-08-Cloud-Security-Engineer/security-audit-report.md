# Security Audit Report

## 1. Principle of Least Privilege (PoLP)

The Principle of Least Privilege means that users and
applications should only have the permissions they need
to perform their assigned tasks. This helps reduce
unauthorized access and limits possible damage if an
account is compromised.

## 2. Attack Surface

The attack surface refers to all the possible ways an
attacker could access or exploit a server. Examples
include open network ports, running services, and
unsecured applications.

## 3. Default Deny Policy

A Default Deny policy blocks incoming traffic unless
it is specifically allowed by a firewall rule. This is
safer because only approved services can receive
connections instead of allowing everything by default.
