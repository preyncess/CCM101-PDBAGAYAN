# Mission Reflection

## My Learning Experience

This laboratory activity helped me understand the basic ideas and important parts of cloud computing. Among the different infrastructure components, I consider **compute resources** as one of the most important because the CPU and RAM are responsible for processing information, running applications, and handling different tasks. If a server does not have enough computing resources, it may have difficulty running applications and services efficiently.

At the same time, I realized that compute resources cannot work alone. **Storage, networking, and the operating system** are also necessary to make a cloud environment functional. Each component has a specific role, but they work together to support the server and its applications.
