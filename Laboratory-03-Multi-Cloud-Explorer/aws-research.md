# AWS Research

## Brief Overview

Amazon Web Services (AWS) is a cloud computing platform provided by Amazon. It offers many cloud services that organizations can use for computing, storage, databases, networking, security, and other IT needs.

## Global Infrastructure

AWS has a global infrastructure made up of Regions, Availability Zones, and data centers. This infrastructure allows applications and services to operate in different parts of the world and helps improve availability and reliability.

## Cloud Management Console

The AWS Management Console is a web-based interface used to access and manage AWS services. Users can create and configure resources such as virtual machines, storage, databases, and networking services through the console.

## Four Core Services

### 1. Amazon EC2
Amazon EC2 provides virtual servers that can be used to run applications and workloads.

### 2. Amazon S3
Amazon S3 is an object storage service used to store files, documents, images, backups, and other data.

### 3. Amazon VPC
Amazon VPC provides a virtual network where AWS resources can be securely deployed and connected.

### 4. AWS IAM
AWS Identity and Access Management (IAM) controls user access and permissions to AWS resources.

## Three Advantages

1. AWS provides a very wide range of cloud services.
2. It has a large global infrastructure.
3. It can scale resources according to business requirements.

## Typical Enterprise Use Cases

AWS is commonly used for web applications, mobile applications, data storage, backup and disaster recovery, enterprise applications, databases, and large-scale cloud infrastructure.
